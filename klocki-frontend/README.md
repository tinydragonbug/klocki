# Klocki — Frontend (React & TypeScript)

**PL:** Klocki to wieloosobowa gra logiczno-strategiczna. To repozytorium zawiera kod interfejsu użytkownika (Frontend), obsługujący zarówno główny ekran gry (TV/Monitor), jak i kontrolery mobilne graczy (Smartfony).
**EN:** Klocki is a multiplayer logic and strategy game. This repository contains the UI code (Frontend), supporting both the main game screen (TV/Monitor) and mobile player controllers (Smartphones).

## Repozytorium Backendowe / Backend Repository
Logika gry i serwer WebSocket znajdują się w osobnym repozytorium: `[Tutaj wkleisz link do klocki-backend]`

## Stos Technologiczny / Tech Stack
* **React** + **TypeScript** (Logika widoków i typowanie)
* **Vite** (Narzędzie do budowania i serwowania aplikacji)
* **WebSockets** (Komunikacja w czasie rzeczywistym z serwerem)
