# Klocki — Multiplayer Blokus Web Game

Nowoczesna, przeglądarkowa implementacja strategicznej gry planszowej Blokus dla 4 graczy z pełnym wsparciem rozgrywki wieloosobowej w czasie rzeczywistym oraz zintegrowaną sztuczną inteligencją (AI).

## 🚀 Technologie
* **Backend:** Python 3.12, FastAPI, WebSockets, asyncio, Pytest.
* **Frontend:** React 18, TypeScript, Vite, @dnd-kit (Drag and Drop).
* **Infrastruktura:** Docker, Docker Compose, Nginx (Reverse Proxy).
